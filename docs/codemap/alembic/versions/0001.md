# alembic/versions/0001_initial_schema.py

**Revision ID**: `0001`  
**Create Date**: 2026-05-18  
**用途**：初始 migration，建立完整 DB schema。

## upgrade() 執行順序

| 步驟 | 操作 | 備註 |
|------|------|------|
| 1 | `CREATE SCHEMA market` | |
| 2 | `CREATE SCHEMA trading` | |
| 3 | `public.users` | email UNIQUE index |
| 4 | `market.instruments` | |
| 5 | `market.market_quotes` | FK → instruments.symbol |
| 6 | `market.intraday_candles` | UNIQUE + index |
| 7 | `market.historical_candles` | UNIQUE + index |
| 8 | `trading.portfolios` | FK → users |
| 9 | `trading.holdings` | FK → users，UNIQUE |
|   | ↳ `ALTER TABLE` | 追加 `market_value`、`unrealized_pnl`（GENERATED ALWAYS AS STORED）|
| 10 | `trading.trades` | FK → users，2 個 index |
| 11 | `trading.ai_decisions` | FK → users，index |
| 12 | `trading.daily_performance` | FK → users，UNIQUE |

## downgrade() 執行順序

反向 drop（daily_performance → ai_decisions → trades → holdings → portfolios →
historical_candles → intraday_candles → market_quotes → instruments → users →
DROP SCHEMA trading → DROP SCHEMA market）

## 注意

`GENERATED ALWAYS AS STORED` 欄位無法在 `op.create_table()` 直接宣告，
必須在建表後用 `op.execute("ALTER TABLE trading.holdings ADD COLUMN ...")` 補加。
