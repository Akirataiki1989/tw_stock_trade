**用途**：新增 `trading.watchlist` 資料表，供 ARQ Worker 決定 quote 同步範圍。

## upgrade() 執行順序

| 步驟 | 操作 | 備註 |
|------|------|------|
| 1 | `CREATE TABLE trading.watchlist` | FK → `public.users.id`（CASCADE）、`market.instruments.symbol` |
|   | ↳ UNIQUE `(user_id, symbol)` | 同用戶不重複 |
| 2 | `CREATE INDEX idx_watchlist_user` | 加速 user_id 查詢 |

## downgrade() 執行順序

| 步驟 | 操作 |
|------|------|
| 1 | `DROP INDEX trading.idx_watchlist_user` |
| 2 | `DROP TABLE trading.watchlist` |

## 設計說明

- `holdings` 與 `watchlist` 允許相同 symbol 共存（語意不同：持有 vs. 追蹤）
- ARQ Worker 查詢時用 `holdings UNION watchlist`（自動去重），避免重複 API 請求
