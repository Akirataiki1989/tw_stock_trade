# v0.6.0 — 2026-06-14

## 新增

### LangGraph Agent (Step 6)

#### 新模組：`app/agent/`
- **`state.py`**：定義 `AnalystReport`、`DebateState`、`FinalDecision` 及 `GraphState`。`analyst_reports` 使用 `operator.add` reducer 支援平行節點處理。
- **`memory.py`**：實作 `AsyncPostgresSaver` 與 `AsyncPostgresStore` (pgvector) 的生產環境初始化。包含向量記憶搜尋、格式化及清理功能。
- **`prompts.py`**：包含 6 個分析師與研究員的提示詞常數（TECHNICAL/SENTIMENT/RISK ANALYST, BULL/BEAR RESEARCHER, RESEARCH_MANAGER）。
- **`nodes.py`**：實作 8 個節點工廠與 2 個獨立節點（含熔斷機制、辯論初始化、結果持久化等）。
- **`graph.py`**：建構編排 LangGraph 流程，整合 LLM 與記憶體後端。

#### 新 Migration (`0004_add_pgvector_settings.py`)
- 安裝 `pgvector` 擴充功能。
- 建立 `trading.settings` 表（`key` PK, `value` TEXT），儲存系統層級參數。
- 初始資料：`ai_interval_minutes = 30`。

#### AI 排程任務 (`app/tasks.py`)
- **`task_maybe_run_ai`**：每分鐘觸發，檢查交易時間與間隔後執行 AI 決策。
- **`task_update_trade_outcomes`**：每日 17:00 更新決策後續績效分數。
- **`task_cleanup_checkpoints`**：每日 03:00 清理過期 Checkpoints。
- **`task_prune_store_memories`**：每週日 02:00 清理過量向量記憶。

#### 核心配置與 Worker 整合
- **`config.py`**：新增 Gemini 模型設定、辯論輪數、向量相似度閾值等 AI 參數。
- **`worker.py`**：`startup` 初始化 `AsyncPostgresSaver`、`GoogleGenerativeAIEmbeddings`、`AsyncPostgresStore`；`shutdown` 確保清理。
- **`pyproject.toml`**：新增 `psycopg[binary,pool]>=3.0`、`langgraph-checkpoint-postgres>=2.0.0`。

#### 測試
- 新增 `tests/agent/` 共 15 項測試（state, memory, nodes, graph integration），全部通過。

## 技術備註

- **初始化 Pattern**：`AsyncPostgresSaver` 與 `AsyncPostgresStore` 必須在 `startup` 透過 `contextlib.AsyncExitStack` (或 `_cm` 管理) 確保非同步 context 正確開啟與關閉。
- **向量儲存坑**：`InMemoryStore` 在 search 時若 `score=None` 會導致排序失效，生產環境使用的 `AsyncPostgresStore` (pgvector) 已透過自訂 `search_patterns` 確保穩定性。
- **熔斷機制**：若風險分析師給出 `HOLD` 建議且信心度 $\ge 0.8$，則跳過後續辯論流程直接進入決策。
