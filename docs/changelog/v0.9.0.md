# v0.9.0 — 2026-06-19

## 後端修正

### CORS
- `app/core/config.py` 新增 `cors_origins: list[str]`（預設 `["http://localhost:3000"]`）
- `app/main.py` 加 `CORSMiddleware`，允許前端 dev server 跨域呼叫 API

### WebSocket bug fix
- `app/api/ws.py` 的 `_forward()` 有 race condition：`pubsub.listen()` 在還沒訂閱任何 channel 時會立即返回，導致 `forward_task` 瞬間完成、觸發 `asyncio.wait(FIRST_COMPLETED)` 把整個 WS 連線拆掉（client 端看到 OPEN 後立刻 CLOSE 1006）
- 修法：`_forward()` 改成外層 `while True` 迴圈，等 `pubsub.subscribed` 為真才進入 `listen()`
- 這個 bug 影響所有 `/ws/quotes` client，不限於這次前端整合——報價推送功能此前從未真正生效過

### NAS .venv 自我修復
- `scripts/start_api.sh`、`scripts/start_worker.sh` 開頭加檢查：`.venv/bin/python` 或對應執行檔不存在就自動 `rm -rf .venv && uv sync --python 3.12`
- 背景：NAS 上 `.venv` 損壞情況頻繁發生，過去都要手動 SSH 重建，現在開機/重啟時會自動偵測修復

## Frontend：tw-stock-trade-web 倉庫建立

- Next.js 15 + shadcn/ui (radix, nova preset) + Tailwind v4 鷹架完成
- Header 元件（依 Option B spec）：Logo / 即時報價 ticker / Market+API 狀態 dot / 暗色主題切換
- Auth 串接：`AuthProvider` context（token 存 localStorage）、Login 表單（呼叫 `/api/v1/auth/jwt/login`）、`useQuoteStream` hook 接 `/ws/quotes`、Logout
- Market 狀態 dot 用台北時間動態算開盤時段，不是寫死的值
- 已用 Playwright 端對端驗證：登入前顯示 Login 表單、登入後即時報價正確顯示並變色、API dot 反映真實 WS 連線狀態、Logout 正確清除 token、瀏覽器 console 無錯誤
