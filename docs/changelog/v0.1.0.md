# Changelog

## [0.1.0] - 2026-05-18

### 初始版本

#### 環境建置
- 建立 `pyproject.toml`，使用 `uv` 管理套件
- Python 3.12，`[dependency-groups]` 管理 dev 依賴
- Ruff 設定：`line-length=100`，`select=["E","F","I"]`

#### 資料庫
- PostgreSQL 三層 Schema 設計
  - `public`：認證（fastapi-users）
  - `market`：純市場資料（instruments、market_quotes、intraday_candles、historical_candles）
  - `trading`：AI 模擬交易（portfolios、holdings、trades、ai_decisions、daily_performance）
- SQLAlchemy 2.0 async models（`Mapped` + `mapped_column`）
- `trading.holdings` 的 `market_value`、`unrealized_pnl` 使用 PostgreSQL `GENERATED ALWAYS AS STORED`
- Alembic async migration（`include_schemas=True`）
- 跨 schema FK：`public.users.id` ← `trading.*`、`market.instruments.symbol` ← `market.market_quotes`

#### 設定
- `pydantic-settings` 讀取 `.env`，Fernet 加密金鑰管理
- `app/core/config.py`、`app/database.py` 建立完成

#### 文件
- `CLAUDE.md`：專案工作指引
- `docs/schema.md`：DB schema 完整規格
- `docs/api.md`：API endpoint 規格（含 request/response 格式）
- `docs/fbs_api.md`：FBS Fubon Neo API 欄位整理
