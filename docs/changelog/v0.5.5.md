# v0.5.5 — 2026-05-25

## 新增

### 外部數據同步（Step 5.5）

#### 新服務：`app/services/external_data.py`
- **Fetch 函式**
  - `fetch_us_market_data()`：透過 yfinance 拉取 S&P500 / NASDAQ / TSM ADR / SOX / DXY / US10Y 昨收
  - `fetch_twse_institutional()`：透過 TWSE T86 API 拉取三大法人買賣超
  - `fetch_twse_margin()`：透過 TWSE MI_MARGN API 拉取融資融券餘額

- **Parse 純函式**
  - `clean_number(s)`：移除千位分隔符與符號，轉換為 float
  - `parse_institutional_row(row, symbol, date)`：從 TWSE 原始列解析三大法人買賣超
  - `parse_margin_row_full(row, symbol, date)`：從 TWSE 原始列解析融資融券餘額

- **Upsert 函式**（支援 ON CONFLICT DO NOTHING / UPDATE）
  - `upsert_us_market_daily(db, data)`：每日一筆 us_market_daily
  - `upsert_institutional_flows(db, data)`：per-symbol institutional_flows
  - `upsert_margin_trading(db, data)`：per-symbol margin_trading

#### 新 DB 表（migration `0003_add_external_data_tables.py`）
- **`market.us_market_daily`**
  - 欄位：`date / sp500_close / nasdaq_close / tsm_adr_close / sox_close / dxy_close / us10y_close`
  - PK：`date`，每日一筆

- **`market.institutional_flows`**
  - 欄位：`date / symbol / institutional_buy / institutional_sell / foreign_buy / foreign_sell / dealer_buy / dealer_sell`
  - PK：`(date, symbol)`，per-symbol per-day

- **`market.margin_trading`**
  - 欄位：`date / symbol / finance_balance / finance_buy / finance_sell / short_balance / short_buy / short_sell`
  - PK：`(date, symbol)`，per-symbol per-day

#### ORM Models（`app/models/market.py`）
- `UsMarketDaily`、`InstitutionalFlow`、`MarginTrading`

#### ARQ Worker 整合（`app/tasks.py` + `app/worker.py`）
- **`task_sync_us_market`**：08:30 每日執行
- **`task_sync_institutional_flows`**：16:00 每日執行
- **`task_sync_margin_trading`**：16:05 每日執行
- 新增至 `worker.py` 的 `cron_jobs` 列表

#### 依賴
- **`pyproject.toml`**：新增 `yfinance>=0.2.54`

#### 測試
- **`tests/test_external_data.py`**：pure parsing functions 單元測試

## 技術備註

- yfinance 與 TWSE API 均為同步呼叫，透過 `asyncio.to_thread()` 包裝非同步上下文
- TWSE API 無需認證金鑰，自由存取
- us_market_daily per-day（無 per-symbol 維度），institutional_flows 與 margin_trading 為 per-symbol per-day
- 三個新 cron tasks 運行時間選在盤後（16:00~16:05），避免與行情更新衝突
