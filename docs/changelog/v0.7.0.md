# v0.7.0 — 2026-06-14

## 新增

### WebSocket 即時推送 (Step 7)

#### WebSocket 端點 (`app/api/ws.py`)
- **`WS /ws/quotes`**：支援即時報價訂閱。Client 可發送 `subscribe` 或 `unsubscribe` 指令來管理感興趣的標的。
- **`WS /ws/ai-stream`**：支援 AI 分析進度追蹤。透過 `session_id` 監聽特定的分析任務，並在收到 `completed` 或 `failed` 終端事件後自動斷開連線。
- **JWT 驗證**：因應瀏覽器限制，採用 Query Parameter (`?token=...`) 進行認證，並確保 `audience` 正確設定為 `fastapi-users:auth`。

#### Redis Pub/Sub 機制 (`app/services/pubsub.py`)
- 實作 Redis 發佈/訂閱封裝，解耦資料產生者（ARQ Worker）與消費者（FastAPI WebSocket）。
- **`publish_quote`**：發佈最新報價至 `quotes:{symbol}` 頻道。
- **`publish_ai_event`**：發佈 AI 分析狀態（started/completed/failed）至 `ai:stream:{session_id}` 頻道。
- 採用 **Fire-and-forget** 模式，確保訊息推送不阻塞核心業務邏輯。

### 核心功能整合
- **`app/tasks.py`**：在 `task_sync_quotes` 成功同步報價後觸發 `publish_quote`；在 `task_run_ai_on_demand` 的生命週期中發佈 AI 事件。
- **`app/worker.py`**：在 Worker 啟動時建立 Redis 連線池並存入 `ctx['redis']`。
- **`app/main.py`**：掛載全新的 WebSocket 路由。
- **`pyproject.toml`**：新增 `redis>=5.0.0` 依賴。

## 測試
- 新增 `tests/test_ws.py`，包含 4 項整合測試（認證、報價訂閱、AI 進度推送、自動斷線機制），全部通過。

## 技術備註
- **Query Param 認證安全**：雖然 Token 暴露在 URL 中，但在 HTTPS 環境下仍具備基本安全性。後續可考慮結合的一次性 Ticket 機制進一步加強。
- **自動重連**：目前後端不處理 Client 端的重連邏輯，建議 Client 端實作 Exponential Backoff 重連機制。
