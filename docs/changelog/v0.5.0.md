# v0.5.0 — 2026-05-24

## 新增

### FBS SDK 接入（Step 4）

- **`app/services/fbs.py`**：`FbsClient` singleton 封裝
  - `connect()` / `disconnect()` / `is_connected()`：SDK 連線生命週期管理
  - `sync_instruments(db)`：全量 upsert `market.instruments`（FBS `tickers()` bulk call）
  - `sync_quote(db, symbol)`：upsert `market.market_quotes`，429 時回傳 False 不拋例外
  - `sync_intraday_candles(db, symbol, timeframe)`：ON CONFLICT DO NOTHING upsert
  - `sync_historical_candles(db, symbol, timeframe, from_date, to_date)`：ON CONFLICT DO UPDATE upsert
  - `fetch_quote(symbol)` / `fetch_candles(...)`：on-demand 查詢，不存 DB（供 FastAPI endpoint 使用）

- **`trading.watchlist` 表**（migration `0002_add_watchlist.py`）
  - 欄位：`id / user_id（FK users）/ symbol（FK instruments）/ added_at`
  - UNIQUE `(user_id, symbol)`
  - ARQ Worker 以 `holdings UNION watchlist` 決定報價同步範圍

- **`app/models/portfolio.py`**：新增 `Watchlist` ORM class
- **`tests/test_fbs.py`**：FbsClient 單元測試（mock SDK，涵蓋 sync/fetch 所有方法）
- **`.python-version`**：鎖定 Python 3.12，防止 uv 自動選 3.14+

## 技術備註

- FBS SDK 為同步 API，所有呼叫透過 `asyncio.to_thread()` 包裝
- 進程退出時 SDK C extension 可能出現 Segmentation fault（已知問題，ARQ Worker 長跑環境不受影響）
- DB hostname 由 `PostgreSQL`（僅 Docker 內部解析）修正為 `localhost:2665`（host port mapping）
